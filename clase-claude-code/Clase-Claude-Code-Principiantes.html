¿Qué es Claude Code y para qué sirve?

Entendiendo la herramienta antes de usarla

Claude Code es una herramienta de inteligencia artificial creada por la empresa Anthropic. Con ella puedes construir, editar y entender proyectos digitales escribiendo en español, como si le hablaras a una asistente muy capaz.

No necesitas saber programar para usarlo. Lo que sí necesitas es aprender a dar instrucciones claras.

💡 Analogía

Claude Code es como tener una arquitecta digital a tu lado. Tú le dices qué quieres construir o cambiar, y ella lo hace. Tú no necesitas saber cómo mezclar el cemento — solo necesitas saber qué quieres.

¿En qué se diferencia Claude normal de Claude Code?

¿Qué puedes hacer con Claude Code?

  • Crear páginas web desde cero sin escribir código
  • Editar textos, colores y diseños de una página existente
  • Agregar funciones nuevas a tu sitio o aplicación
  • Entender qué hace el código que ya tienes
  • Construir herramientas propias como el CRM de Claudia Spring

Pasos exactos para entrar por primera vez

Los tres ingredientes de toda página web

Lo que necesitas entender antes de tocar cualquier archivo

Toda página web — sin excepción — está hecha de exactamente tres cosas. Siempre las tres, siempre trabajando juntas:

🦴

HTML — La estructura

Es el esqueleto. Define qué elementos existen y en qué orden aparecen en la página.

👗

CSS — El diseño

Es la ropa. Define colores, tamaños, fuentes, espacios y formas de cada elemento.

🧠

JavaScript — El comportamiento

Es el cerebro. Define qué pasa cuando interactúas: clics, guardados, cálculos, filtros.

Ejemplo con el CRM de Claudia Spring

Cuando ves el botón morado que dice "+ Nueva clienta", eso es la combinación de los tres:

HTML — qué existe <!-- Esto crea el botón --> <button onclick="openModal()"> + Nueva clienta </button>
CSS — cómo se ve /* Esto lo hace morado y elegante */ .btn-add { background: linear-gradient(135deg, #5B2C83, #7B3FAD); color: #fff; border-radius: 8px; padding: 9px 16px; }
JavaScript — qué hace // Esto abre el formulario al hacer clic function openModal() { // muestra el formulario de nueva clienta document.getElementById('modal-overlay') .classList.add('open'); }
💡 Para recordar siempre

HTML dice qué hay. CSS dice cómo se ve. JavaScript dice qué hace. Si algo no se ve bien → CSS. Si algo no funciona → JavaScript. Si falta algo → HTML.

Cómo leer un archivo HTML

El mapa que necesitas para no perderte

Todo archivo .html tiene la misma estructura básica, como un libro con partes fijas:

Estructura de todo archivo HTML <!DOCTYPE html> ← Le dice al navegador: "esto es HTML" <html> <head> ← Información invisible para el usuario <title>Mi página</title> ← Título de la pestaña <style> ← Aquí vive el CSS (diseño) ... </style> </head> <body> ← Todo lo que se VE en pantalla <h1>Título grande</h1> <p>Un párrafo</p> <button>Un botón</button> </body> <script> ← Aquí vive el JavaScript (comportamiento) ... </script> </html>

La regla de oro — etiquetas que abren y cierran

Cada elemento en HTML tiene una etiqueta que abre y una que cierra. La barra / siempre indica el cierre:

EtiquetaQué creaEjemplo
<h1> </h1>Título muy grandeEl título principal de una página
<h2> </h2>Título grandeEncabezados de secciones
<p> </p>Párrafo de textoCualquier texto descriptivo
<button> </button>BotónBotón de acción o envío
<div> </div>Caja contenedoraAgrupa otros elementos
<a> </a>EnlaceTexto que lleva a otro lugar

Las cajas dentro de cajas

El HTML funciona como cajas que contienen otras cajas. El banner de bienvenida del CRM, por ejemplo, se ve así por dentro:

Ejemplo real del CRM ┌─── div.welcome (caja grande — el banner morado) ──┐ │ │ │ ┌── h2 ─────────────────────────────────────┐ │ │ │ Bienvenida al CRM Renacer en Fe y Amor │ │ │ └────────────────────────────────────────────┘ │ │ │ │ ┌── p ──────────────────────────────────────┐ │ │ │ Este sistema te ayuda a organizar... │ │ │ └────────────────────────────────────────────┘ │ │ │ └───────────────────────────────────────────────────┘
💡 Para cambiar un texto

Solo tienes que editar lo que está entre las etiquetas. Si quieres cambiar el título, editas lo que hay entre <h2> y </h2>. Todo lo demás queda igual.

5

Cómo dar instrucciones claras

La habilidad más importante para trabajar con Claude Code

Una instrucción bien escrita produce resultados precisos. Una instrucción vaga produce resultados vagos. Esta es la habilidad central que debes desarrollar.

La fórmula de una buena instrucción

📝 Fórmula

[En qué archivo] + [Qué quiero cambiar] + [Cómo quiero que quede]

Ejemplos: instrucción vaga vs instrucción clara

❌ Instrucción vaga

  • Cambia el texto
  • Pon un color diferente
  • Agrega algo ahí
  • Hazlo más bonito

✅ Instrucción clara

  • En el archivo X, cambia el título que dice "Y" por "Z"
  • Cambia el color dorado de #C9A646 a #D4AF37
  • Agrega un campo llamado "Edad" entre Ciudad y País
  • Explícame qué cambió y por qué

Instrucciones reales que puedes usar

Para cambiar un texto En el archivo CRM-Renacer-en-Fe-y-Amor-FINAL.html, cambia el título del banner de bienvenida. Quiero que diga: "Con amor y claridad, organizo mi misión." No toques nada más.
Para cambiar un color En el archivo CRM-Renacer-en-Fe-y-Amor-FINAL.html, cambia el color dorado de #C9A646 a #D4AF37. Solo ese valor, en todas las partes donde aparezca. Explícame cuántos lugares cambiaron.
Para entender algo Sin modificar nada, explícame para qué sirve la función "exportar" en el archivo CRM-Renacer-en-Fe-y-Amor-FINAL.html. Explícamelo como si fuera principiante.
💡 Consejo de oro

Siempre incluye el nombre exacto del archivo. Así Claude sabe exactamente dónde trabajar y no toca los demás archivos por accidente.

Reglas de seguridad

Protege tu trabajo antes de hacer cualquier cambio

Antes de pedirle a Claude que modifique algo, incluye siempre estas frases protectoras en tu instrucción:

Frases de seguridad — úsalas siempre No borres archivos existentes. No elimines funciones actuales. No cambies lo que no te pido. Explícame exactamente qué cambiaste después de hacerlo.

Qué hacer si algo sale mal

Si haces un cambio y el resultado no es lo que esperabas, escribe una de estas frases:

Para deshacer un cambio Eso no quedó como esperaba. Por favor revierte el último cambio y déjalo exactamente como estaba antes.
Para entender qué pasó Explícame qué cambió exactamente y por qué no se ve como yo esperaba.
Para empezar de nuevo Descarta ese cambio. Quiero intentarlo de otra manera. Antes de hacer cualquier cosa, explícame el plan.
✅ Recuerda siempre

Claude puede deshacer, explicar y volver a intentarlo. Nunca tienes que sentir que rompiste algo sin solución. Siempre hay una forma de recuperarte.

Reglas de oro para principiantes

✅ Haz esto

  • Cambia una cosa a la vez
  • Pide explicación antes de cambios grandes
  • Exporta un respaldo antes de modificar
  • Lee lo que Claude explica antes de continuar
  • Pregunta si no entiendes algo

❌ Evita esto

  • Pedir muchos cambios a la vez
  • Dar instrucciones sin nombre de archivo
  • Aceptar cambios sin leer la explicación
  • Modificar sin tener respaldo guardado
  • Apresurarte cuando algo no funciona

Tus 5 ejercicios de práctica

Del más fácil al más desafiante — basados en el CRM real de Claudia Spring

Estos ejercicios usan el archivo real CRM-Renacer-en-Fe-y-Amor-FINAL.html. Están ordenados por dificultad. Empieza por el primero y avanza cuando te sientas cómoda.

Ejercicio 1 — Nivel básico

Cambiar el texto del banner de bienvenida

El panel principal del CRM tiene un banner morado con un título y una descripción. Tu tarea es cambiar ese texto por uno que tú elijas.

Instrucción que debes escribir:

En el archivo CRM-Renacer-en-Fe-y-Amor-FINAL.html, cambia el texto del banner de bienvenida. Título nuevo: [escribe tu título aquí] Descripción nueva: [escribe tu descripción aquí] No toques nada más. Explícame qué línea cambiaste.
Lo que aprenderás: dónde viven los textos en el HTML
Ejercicio 2 — Nivel básico

Cambiar el color dorado

El CRM usa el color dorado #C9A646 en botones, títulos y acentos. Tu tarea es cambiarlo por otro tono de dorado y ver cómo afecta todo el sistema.

Instrucción que debes escribir:

En el archivo CRM-Renacer-en-Fe-y-Amor-FINAL.html, cambia el color dorado de #C9A646 a #D4AF37. Solo ese valor en todas las partes donde aparezca. Después dime cuántos lugares cambiaron y dónde.
Lo que aprenderás: cómo una variable CSS afecta todo el diseño
Ejercicio 3 — Nivel intermedio

Agregar un campo al formulario

El formulario de nueva clienta tiene campos como Nombre, WhatsApp, País y Ciudad. Tu tarea es agregar un campo nuevo llamado "Edad aproximada".

Instrucción que debes escribir:

En el archivo CRM-Renacer-en-Fe-y-Amor-FINAL.html, agrega un campo llamado "Edad aproximada" en el formulario de nueva clienta, entre los campos de Ciudad y Red social. No elimines ningún campo existente. Explícame en qué partes del archivo hiciste cambios.
Lo que aprenderás: cómo se conecta el HTML del formulario con el JavaScript
Ejercicio 4 — Nivel intermedio

Cambiar el mensaje de WhatsApp

Cuando haces clic en WhatsApp desde el perfil de una clienta, se envía un mensaje prellenado. Tu tarea es cambiar ese mensaje por uno con tus propias palabras.

Instrucción que debes escribir:

En el archivo CRM-Renacer-en-Fe-y-Amor-FINAL.html, cambia el mensaje prellenado de WhatsApp para contactar clientas. Quiero que diga: [escribe aquí tu mensaje personalizado] Explícame en qué parte del archivo está guardado ese mensaje.
Lo que aprenderás: cómo viven las constantes en JavaScript
Ejercicio 5 — Nivel avanzado

Agregar una nueva etapa al proceso

El CRM tiene 10 etapas del proceso de acompañamiento. Tu tarea es agregar una etapa nueva llamada "En lista de espera", entre "Propuesta enviada" y "Pago pendiente".

Instrucción que debes escribir:

En el archivo CRM-Renacer-en-Fe-y-Amor-FINAL.html, agrega una nueva etapa llamada "En lista de espera" entre "Propuesta enviada" y "Pago pendiente". Después muéstrame en cuántas partes del archivo afectó ese cambio y por qué.
Lo que aprenderás: cómo un dato controla múltiples partes del sistema al mismo tiempo
💡 Antes de cada ejercicio

Exporta un respaldo de tu CRM haciendo clic en el botón "⬇️ Exportar respaldo". Así, si algo no queda como esperabas, puedes restaurar todo con un clic usando "⬆️ Importar respaldo".
